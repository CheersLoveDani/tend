## Default Permission

Allows all Tend native commands and the plugin event listeners (`action`, `pending-actions`).

#### This default permission set includes the following:

- `allow-set-state`
- `allow-get-permissions`
- `allow-request-permission`
- `allow-take-launch-action`
- `allow-take-pending-actions`
- `allow-download-update`
- `allow-install-update`
- `allow-move-to-back`
- `allow-choose-backup-file`
- `allow-backup-target`
- `allow-write-backup`
- `allow-open-backup-file`
- `allow-health-status`
- `allow-health-request`
- `allow-health-read`
- `allow-calendar-status`
- `allow-calendar-request`
- `allow-calendar-list`
- `allow-calendar-events`
- `allow-register-listener`
- `allow-remove-listener`
